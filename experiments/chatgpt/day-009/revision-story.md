# Day009 수정 이야기

처음 화면에서 문제는 비교 방식이었다. 같은 11em에서 두 줄 나눔 규칙을 버튼으로 바꾸면 이전 줄 끝이 사라져 독자가 기억에 의존해야 했다.

원래 가정은 같은 문장과 너비를 유지하고 규칙 하나만 바꾸면 충분하다는 것이었다. 그러나 변수 통제와 직접 비교는 같지 않다. 검토본은 같은 요청 너비와 균형 조건에서 어절 단위와 글자 단위 결과를 동시에 보여 준다. 좌우 위치 효과와 작은 화면에서의 위아래 배치라는 새 한계는 남는다.

근거의 경계도 좁혔다. W3C 문서는 한글 줄 나눔을 글자 또는 어절 단위로 지정할 수 있다고 설명하지만 어느 쪽이 더 잘 읽힌다는 결과는 아니다. 2012년 한국어 교재 연구는 초급과 중급 학습자의 교재에서 어색한 분절 문제를 다루지만 일반 성인과 모든 화면으로 일반화할 수 없다.

이번에 수정한 라이브 제목, 조작부, 상태, 도움말, 접근성 라벨은 영어로 작성했다. 실험 대상인 한글 문장은 연구 재료이므로 그대로 두었다.

두 패널이 같은 문자열과 같은 요청 너비를 쓰는 것은 구현 사실이다. 더 읽기 쉽다거나 어절 보존이 더 좋다는 결론은 아직 증거가 없다. 실제 독자 비교, 스크린리더, 확대, 모바일 터치, 인쇄 교정도 수행하지 못했다.

독자에게 중요한 장면은 줄 끝이 자동 처리의 잔여물이 아니라 언어 단위와 판면의 모양이 충돌하는 편집 지점이라는 사실이다. 다음 단계는 여러 문장과 고정 서체, 고정 화면에서 패널 순서를 바꾸고 선호와 오독을 따로 기록하는 것이다.
